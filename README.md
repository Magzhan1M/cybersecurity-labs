# Labtainer Cybersecurity Labs
# Labtainer is a collection of lab workt that teache you to be an ethical hacker
This repository contains cybersecurity lab exercises using the [Labtainer framework](https://nps.edu/web/c3o/labtainers), developed by the Naval Postgraduate School's Center for Cybersecurity and Cyber Operations. Labtainers provides a set of fully packaged Linux-based computer science lab exercises with an initial emphasis on cybersecurity.

## About Labtainer

Labtainer is a free and open-source framework that allows students to run labs directly on their laptops by installing a single virtual machine appliance. It includes over 50 cyber exercises, covering topics such as:

- Software Vulnerabilities
- Networking
- Network Traffic Analysis
- Cryptography
- Web Security
- Reverse Engineering
- System Security and Operations
- Industrial Control System Security
